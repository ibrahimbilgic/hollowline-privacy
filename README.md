# Hollowline — gizlilik politikası

Hollowline oyununun gizlilik politikası, Türkçe ve İngilizce, tek sayfa.
Yayın: https://ibrahimbilgic.github.io/hollowline-privacy/

Metin şablon değil: oyunun kodundan yazıldı. Hollowline'da ağ isteği yapan tek bir satır yoktur
(`UnityWebRequest`, `HttpClient`, `System.Net` hiç geçmez), bildirim, çökme raporlama ve analitik
hizmeti yoktur. Cihazdan çıkan tek şey Google AdMob'un reklam isteğidir. Politika bunu anlatır.

Oyunun davranışı değişirse bu sayfa da değişmeli — özellikle yeni bir SDK eklenirse.
